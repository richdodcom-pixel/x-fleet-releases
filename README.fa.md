# X-Fleet — نصب

این مخزن نسخه‌های آمادهٔ X-Fleet را نگه می‌دارد (زبانهٔ **Releases**): برنامهٔ لینوکس (amd64 و arm64)،
اسکریپت نصب `install.sh` و چک‌سام‌های `SHA256SUMS`. در ادامه روش نصب آمده است.

X-Fleet پنلی برای مدیریت VPN مبتنی بر Xray روی چندین سرور به‌طور هم‌زمان است. با یک دستور نصب می‌شود،
بدون Docker و بدون پایگاه دادهٔ جداگانه.

> برنامهٔ نصب و رابط پنل به زبان‌های **انگلیسی** و **روسی** در دسترس است. نام منوها و دکمه‌ها در ادامه به انگلیسی و همان‌طور که در پنل دیده می‌شوند آمده است.

## پیش‌نیازها

- یک سرور (VPS) با **Ubuntu 22.04+** یا **Debian 12+** و پردازندهٔ amd64 یا arm64.
- دسترسی **root** از طریق SSH.
- ترجیحاً یک دامنهٔ شخصی (مثلاً `panel.example.com`) با رکورد A به IP سرور.
  بدون دامنه هم می‌شود: پنل از یک نام رایگان مانند `1-2-3-4.sslip.io` استفاده می‌کند.
- پورت‌های باز نزد ارائه‌دهندهٔ سرور (در کنترل‌پنل آن، اگر فایروال جداگانه دارد):

| پورت | کاربرد |
|---|---|
| 80 | Let's Encrypt دامنه را برای صدور گواهی بررسی می‌کند |
| تصادفی (برنامهٔ نصب نشان می‌دهد) | ورود به پنل |
| 8444 | اتصال نودها به پنل |
| 2096 | لینک‌های اشتراک برای کاربران |
| 443 و 8443 | خود VPN (اگر این سرور هم VPN ارائه می‌دهد) |

اگر `ufw` روی سرور فعال باشد، برنامهٔ نصب پورت‌های لازم را خودش در آن باز می‌کند.

## ۱. نصب پنل

با کاربر root وارد سرور شوید و اجرا کنید:

</div>

```bash
bash <(curl -fsSL https://github.com/richdodcom-pixel/x-fleet-releases/releases/latest/download/install.sh)
```

<div dir="rtl">

جادوگر نصب باز می‌شود و گام‌به‌گام سؤال می‌پرسد. اگر مطمئن نیستید Enter را بزنید تا گزینهٔ پیش‌فرض انتخاب شود.

1. **زبان:** روسی یا انگلیسی.
2. **بررسی سیستم و بسته‌ها.** برنامهٔ نصب پیشنهاد به‌روزرسانی سیستم (`apt upgrade`) را می‌دهد.
   روی سروری که از قبل چیزی رویش اجرا می‌شود می‌توانید رد کنید.
3. **آدرس و HTTPS.** دامنهٔ خود را وارد کنید یا گزینهٔ بدون دامنه (sslip.io) را انتخاب کنید.
   پنل گواهی Let's Encrypt را خودش می‌گیرد.
4. **تنظیمات پنل.** پورت، مسیر مخفی و نام کاربری تصادفی انتخاب می‌شوند و رمز عبور خودکار ساخته می‌شود.
5. **VPN روی همین سرور.** می‌توانید همین سرور را بلافاصله اولین نود کنید:
   - VLESS Reality XHTTP روی پورت 443 (اتصال اصلی)؛
   - TCP + Vision روی پورت 8443 (پشتیبان).

   در همین مرحله سایت استتار انتخاب و اولین کاربر ساخته می‌شود.
6. **اجرا و بررسی.** سرویس‌ها اجرا می‌شوند و پس از راه‌اندازی مجدد سرور خودکار بالا می‌آیند.

در پایان **آدرس پنل، نام کاربری و رمز عبور** و کد QR اشتراک اولین کاربر روی صفحه نمایش داده می‌شود.
اطلاعات ورود در فایل `/root/x-fleet-admin.txt` ذخیره می‌شود. برای دیدن دوباره:

</div>

```bash
cat /root/x-fleet-admin.txt
```

<div dir="rtl">

### نصب بدون سؤال

`--yes` را اضافه کنید تا همه چیز پیش‌فرض انتخاب شود. بقیهٔ پارامترها را هم می‌توان مستقیم داد:

</div>

```bash
bash <(curl -fsSL https://github.com/richdodcom-pixel/x-fleet-releases/releases/latest/download/install.sh) --yes --domain panel.example.com
```

<div dir="rtl">

| پارامتر | کارکرد |
|---|---|
| `--lang ru\|en` | زبان برنامهٔ نصب و منو |
| `--domain panel.example.com` | دامنهٔ شخصی برای پنل و اشتراک‌ها |
| `--https le\|ip\|self\|none` | HTTPS: دامنهٔ شخصی / بدون دامنه (sslip.io) / خودامضا / بدون HTTPS (فقط از طریق تونل SSH) |
| `--cert فایل --key فایل` | گواهی خودتان به‌جای Let's Encrypt |
| `--email you@example.com` | ایمیل برای اعلان‌های Let's Encrypt |
| `--port 31234` | پورت پنل (پیش‌فرض: تصادفی) |
| `--login نام` | نام کاربری مدیر (پیش‌فرض: تصادفی) |
| `--connections rec\|xhttp\|vision\|none` | VPN روی این سرور: هر دو اتصال / فقط XHTTP / فقط Vision / هیچ |
| `--mask neighbor\|self\|<سایت>` | استتار Reality: سایت همسایه در همان زیرشبکه / سایت خودتان روی سرور / سایت مشخص‌شده |
| `--user نام` | اولین کاربر (پیش‌فرض `user`) |
| `--name نام` | نام سرور در اپلیکیشن‌های کاربران، با حروف لاتین |
| `--upgrade` / `--no-upgrade` | به‌روزرسانی سیستم یا نه |
| `--bbr` / `--no-bbr` | فعال‌سازی شتاب‌دهی TCP (BBR) یا نه؛ پیش‌فرض فعال است |
| `--version v0.7.1` | نصب یک نسخهٔ مشخص |

راهنمای کامل پارامترها:

</div>

```bash
bash <(curl -fsSL https://github.com/richdodcom-pixel/x-fleet-releases/releases/latest/download/install.sh) --help
```

## ۲. اولین ورود

1. آدرسی را که برنامهٔ نصب نشان داد در مرورگر باز کنید، مثلاً
   `https://panel.example.com:31234/AbCdEf123/`.
   آدرس مخفی است: بدون مسیر درست پنل باز نمی‌شود و اسکنرها آن را پیدا نمی‌کنند.
2. با نام کاربری و رمز عبور موجود در `/root/x-fleet-admin.txt` وارد شوید.
3. پیشنهاد می‌کنیم همان ابتدا:
   - **Settings ← Security**: رمز عبور را عوض کنید و ورود دومرحله‌ای را فعال کنید؛
   - **Settings ← Notifications**: تلگرام را وصل کنید تا از خرابی‌ها باخبر شوید؛
   - **Settings ← System**: پشتیبان‌گیری زمان‌بندی‌شده را فعال کنید.

## ۳. افزودن نود (سرورهای VPN دیگر)

**نود** (node) سروری است که کاربران از طریق آن به VPN وصل می‌شوند. پنل نودها را از راه دور مدیریت می‌کند.
هر نود جدید یک **دستور نصب** لازم دارد. این دستور را خود پنل صادر می‌کند و در GitHub وجود ندارد:
آدرس پنل شما و یک کلید یک‌بارمصرف داخل دستور است.

### گام ۱. دستور را از پنل بگیرید

1. پنل را در مرورگر باز کنید و وارد شوید.
2. از منوی سمت چپ **Nodes** را انتخاب کنید.
3. دکمهٔ آبی **Add node** را بزنید (بالا سمت راست).
4. فرم را پر کنید:

   | فیلد | چه بنویسید |
   |---|---|
   | **Name** | هر نام روشنی با حروف لاتین، مثلاً `amsterdam-1` |
   | **Address (IP or domain)** | IP سرور جدید، مثلاً `203.0.113.10`. کاربران آن را در اشتراک می‌بینند |
   | **Node domain (for camouflage)** | می‌تواند خالی بماند. اگر دامنه‌ای با رکورد A به IP این سرور دارید، واردش کنید، مثلاً `nl1.example.com` |
   | **Country** و **City** | می‌توانند خالی بمانند: پنل آن‌ها را از روی IP تشخیص می‌دهد. کاربران مثلاً `🇳🇱 Netherlands, Amsterdam` را می‌بینند |
   | **Add inbounds from templates right away** | تیک را نگه دارید: اتصال‌های نود خودکار ساخته می‌شوند |

5. **Create** را بزنید.
6. پنجرهٔ **Install node** با یک دستور طولانی باز می‌شود که با `curl -fsSL https://…/node.sh | bash -s -- …` شروع می‌شود.
   روی آیکون **کپی** در سمت راست دستور بزنید.

دستور تقریباً این شکلی است (آدرس، توکن و اثرانگشت شما متفاوت خواهد بود):

</div>

```text
curl -fsSL https://panel.example.com:2096/install/Ab12Cd/node.sh | bash -s -- --panel panel.example.com:8444 --token 7f3a… --pin 9c1e…
```

<div dir="rtl">

> **مهم:** دستور یک‌بارمصرف است و **۱۵ دقیقه** اعتبار دارد (زمان انقضا در پنجره نوشته شده).
> نرسیدید یا پنجره را بستید؟ **Nodes** را باز کنید ← روی نود بزنید ← **New install token**،
> تا دستور تازه‌ای ظاهر شود.

**راه دیگر: از سرور پنل.** با SSH وارد سروری شوید که پنل روی آن نصب است و اجرا کنید:

</div>

```bash
x-fleet node-cmd
```

<div dir="rtl">

برنامه نام نود، IP و دامنهٔ آن را می‌پرسد (Enter: بدون دامنه) و دستور آماده را چاپ می‌کند. اعتبار آن ۳۰ دقیقه است.

### گام ۲. دستور را روی سرور جدید اجرا کنید

1. با SSH و کاربر root وارد **سرور جدید** شوید (نود آینده، نه سرور پنل):

</div>

```bash
ssh root@203.0.113.10
```

<div dir="rtl">

2. دستور کپی‌شده را بچسبانید (در ترمینال: کلیک راست یا Ctrl+Shift+V / Cmd+V) و Enter را بزنید.
3. ۱ تا ۲ دقیقه صبر کنید. نود خودش:
   - برنامه را از پنل شما دانلود و چک‌سام را بررسی می‌کند؛
   - از طریق کانال امن به پنل وصل می‌شود؛
   - Xray را دانلود و اجرا می‌کند.

### گام ۳. بررسی کنید

به پنل برگردید ← **Nodes**. چند ثانیه بعد وضعیت نود جدید سبز می‌شود.
اتصال‌های قالب‌ها از قبل ساخته شده‌اند. نود در اشتراک کاربران گروهی که عضو آن است ظاهر می‌شود
(بخش **Squads**). نیازی به تغییر لینک اشتراک نیست: اپلیکیشن هنگام به‌روزرسانی اشتراک، سرور جدید را دریافت می‌کند.

### اگر نشد

- **"install token expired" (توکن نصب منقضی شده):** دستور جدید بگیرید: صفحهٔ نود ← **New install token**.
- **نود به پنل وصل نمی‌شود:** روی سرور پنل باید پورت **8444** باز باشد
  (و **2096**، برنامه از آن دانلود می‌شود). فایروال ارائه‌دهنده را بررسی کنید.
- **روی سرور جدید از قبل VPN دیگری اجرا می‌شود** (مثلاً 3x-ui) و پورت‌های 443/8443 اشغال‌اند: برنامهٔ نصب متوقف می‌شود
  و نشان می‌دهد کدام برنامه پورت را گرفته است. به این ترتیب VPN قبلی خراب نمی‌شود. پورت‌ها را آزاد کنید یا در پنل
  پورت‌های دیگری به این نود بدهید.
- **نود همان سرور پنل است:** چیزی لازم نیست نصب کنید، جادوگر نصب پنل از همان ابتدا این را پیشنهاد می‌دهد (گام «VPN روی همین سرور»).

## ۴. کاربران و اشتراک‌ها

**Users** ← **New user**. هر کاربر یک لینک اشتراک دارد که به اپلیکیشن اضافه می‌شود.
صفحهٔ اشتراک یک کد QR و دکمه‌هایی برای اپلیکیشن‌ها نشان می‌دهد.

### اپلیکیشن‌های کاربران

| اپلیکیشن | افزودن اشتراک |
|---|---|
| **NOX** (پیشنهادی، Android 7+) | [دانلود NOX.apk](https://github.com/richdodcom-pixel/nox-updates/releases/latest/download/NOX.apk). دکمهٔ **NOX** در صفحهٔ اشتراک اپلیکیشن را باز و اشتراک را اضافه می‌کند |
| Happ، Hiddify، INCY، v2RayTun، Streisand، v2rayNG، Clash Verge / FlClash | دکمهٔ اپلیکیشن در صفحهٔ اشتراک (یا لینک اشتراک را در اپلیکیشن بچسبانید) |
| sing-box و دیگر کلاینت‌های Clash / Mihomo | لینک اشتراک را بچسبانید؛ پنل خودش قالب مناسب را می‌دهد |

## مدیریت از سرور: دستور `x-fleet`

روی سرور `x-fleet` را تایپ کنید تا منو باز شود. دستورهای سریع:

| دستور | کارکرد |
|---|---|
| `x-fleet url` | نمایش آدرس پنل و نام کاربری |
| `x-fleet password` | رمز عبور جدید مدیر |
| `x-fleet 2fa off` | خاموش کردن ورود دومرحله‌ای (اگر گوشی را گم کرده‌اید) |
| `x-fleet status` | وضعیت سرویس‌ها |
| `x-fleet restart` | راه‌اندازی مجدد سرویس‌ها |
| `x-fleet log` | گزارش |
| `x-fleet port 31234` | تغییر پورت پنل |
| `x-fleet path` | مسیر مخفی جدید پنل |
| `x-fleet https` | گواهی پنل |
| `x-fleet update` | به‌روزرسانی X-Fleet |
| `x-fleet backup` | پشتیبان‌گیری همین حالا |
| `x-fleet check` | بررسی سرور |
| `x-fleet link نام` | لینک اشتراک کاربر با کد QR |
| `x-fleet node-cmd` | دستور نصب نود جدید |

## به‌روزرسانی

- **پنل:** **Settings ← System ← Panel update**. یا روی سرور: `x-fleet update`.
  نسخهٔ قبلی برای بازگشت نگه داشته می‌شود.
- **نودها:** **Settings ← Cores**: به‌روزرسانی Xray و ایجنت‌ها روی همهٔ نودها به‌یکباره.
  یا تک‌تک در صفحهٔ نود. **Settings ← System ← Update all servers** همهٔ نودها را با یک کلیک به‌روز می‌کند.

## تغییر آدرس یا دامنهٔ پنل

**Settings ← Network & certificates**. اینجا پورت، مسیر مخفی و گواهی تغییر می‌کند
(دامنهٔ شخصی، sslip.io یا خودامضا).

- پنل گواهی دامنهٔ جدید را **پیش از** تغییر می‌گیرد. اگر Let's Encrypt رد کند، چیزی تغییر نمی‌کند
  و دلیل روی صفحه نمایش داده می‌شود.
- پس از تغییر، پنل را با آدرس جدید باز کنید و **ظرف ۱۰ دقیقه** وارد شوید. در غیر این صورت تنظیمات قبلی خودکار برمی‌گردد
  و دسترسی از دست نمی‌رود.

## اگر چیزی کار نکرد

- **گواهی صادر نمی‌شود:**
  - بررسی کنید رکورد A دامنه به IP سرور اشاره کند و در Cloudflare ابر خاکستری (فقط DNS) باشد؛
  - بررسی کنید پورت 80 نزد ارائه‌دهنده باز باشد؛
  - Let's Encrypt برای هر نام حداکثر ۵ گواهی در هفته صادر می‌کند. اگر زیاد دوباره نصب می‌کنید صبر کنید
    یا موقتاً گزینهٔ بدون دامنه (sslip.io) را انتخاب کنید.
- **آدرس یا رمز عبور را فراموش کرده‌اید:** وارد سرور شوید و `x-fleet url` یا `x-fleet password` را اجرا کنید.
- **بررسی کلی:** `x-fleet check`.

## حذف

</div>

```bash
x-fleet uninstall
```

<div dir="rtl">

این دستور سرویس‌ها را متوقف می‌کند و برنامه، تنظیمات و داده‌ها را پاک می‌کند. پشتیبان‌ها در `/var/lib/x-fleet/backups` باقی می‌مانند.

## برای به‌روزرسانی از نسخه‌های قدیمی (nodepanel)

پیش از v0.5.0 نام برنامه `nodepanel` بود. هنگام به‌روزرسانی با دکمه، همه چیز خودکار به نام‌های جدید منتقل می‌شود:

| قبلاً | اکنون |
|---|---|
| `/usr/local/bin/nodepanel` | `/usr/local/bin/x-fleet` (نام قدیمی به‌صورت پیوند باقی می‌ماند) |
| سرویس‌های `nodepanel-panel`، `nodepanel-node` | `x-fleet-panel`، `x-fleet-node` |
| `/etc/nodepanel`، `/var/lib/nodepanel`، `/var/lib/nodepanel-node` | `/etc/x-fleet`، `/var/lib/x-fleet`، `/var/lib/x-fleet-node` |
| `/root/nodepanel-admin.txt` | `/root/x-fleet-admin.txt` |

اگر سرویس جدید بالا نیاید، همه چیز به حالت قبل برمی‌گردد. برای تکرار دستی: `x-fleet migrate`؛
گزارش انتقال: `journalctl -u x-fleet-migrate`.
